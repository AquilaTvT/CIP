# Plume learning sequence

New learners can begin with Foundations before entering the AtCoder library. Its seven chapters and 28 lessons move from Python input and execution to debugging, complexity, sequence queries, graph search, dynamic programming, a complete problem-solving workflow, and the skills specific to the programming exam: data files, recursion, shortest paths and simulation. Each lesson includes detailed explanations, execution traces, runnable examples with input/output, self-check questions, an original exercise, reference implementations, and follow-up problems. All content is available locally in Chinese, English, and Japanese. See [ACADEMY.md](ACADEMY.md) for the lesson outline and content validation.

Course completion records successful checks for the lesson's saved program. It is separate from manual problem completion, official AtCoder acceptance, and mock-exam scores. Learners should use each lesson's linked problems to apply the concept independently; viewing a reference implementation is not itself a completion.

The six levels describe a learning progression, not a prediction of entrance-exam marks. AtCoder letters are contest positions; prerequisites and the required reasoning determine the sequence here.

L0 begins with `PracticeA`, then addition, arithmetic, simple conditionals, strings, and short loops. List traversal and two-dimensional tables follow. Frequency dictionaries, functions, bitwise operations, and the recursive organization-tree exercise come last. In particular, `APG4bPython EX18` requires substantially more preparation than the beginning of L0 and is its final exercise.

The revision changes only the 33 L0 `order` values. It retains every task's level, standard identifier, statement, and `globalOrder`, preserving saved progress and stable references. The library and previous/next navigation use `level` followed by `order`.

Study recommendations first use the lowest unfinished level. Within that level, bookmarked exercises and exercises with previous mistakes receive priority; otherwise they follow the curriculum order. Harder bookmarked problems remain accessible through Review and the library.

The original CI sets sit outside the six levels as a separate pack. Each set is one exam-style question: a scenario, usually a data file to read, and four parts of rising difficulty, worth 100 points in total. They suit the later stages of preparation, after L2–L3, and can be taken as timed mock exams scored per part.

This order assumes a learner is acquiring Python syntax alongside practice. APG exercises are practice tasks with explicit templates or requirements, not replacements for the corresponding language lessons. Neither completing every problem nor a high local mock score guarantees a particular University of Tokyo exam score.
