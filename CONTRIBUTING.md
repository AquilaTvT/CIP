# Contributing

Keep changes focused and include a reproducible check for behavior changes.

Problem IDs are stable identifiers. Preserve existing IDs and local-storage keys so that upgrades retain progress. Problem text must be stored locally in Chinese, English, and Japanese. Do not substitute another language for a missing translation or add a translation service to the reading path.

For each statement change, check the problem definition, all constraints, input and output formats, examples, and any explanatory diagrams. Preserve spaces and line breaks inside sample input/output and source code. A local sample match is not an official accepted submission.

Do not commit personal progress exports, credentials, or downloaded submission histories. Third-party problem content and bundled runtimes retain their original ownership and notices.
